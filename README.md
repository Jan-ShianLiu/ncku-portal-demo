# 學籍資料入口介面模擬器

依提供的四張畫面截圖製作：藍色入口 → 白色登入頁 → 藍底功能選單 → 白底藍表格學籍資料頁。
純 HTML / CSS / JavaScript，不需安裝套件或執行建置。

## 在自己的電腦開啟

解壓縮後，使用瀏覽器開啟 `index.html`，點擊「使用成功入口 登入」。
所有檔案與 assets 資料夾必須保持相同相對位置。

## 部署 GitHub Pages

1. 在 GitHub 建立 repository，例如 `ncku-portal-demo`。
2. 上傳本資料夾**裡面的內容**（讓 index.html 位於 repository 根目錄），包含 assets 資料夾及 .nojekyll。
3. 前往 Settings → Pages。
4. Source 選 Deploy from a branch，Branch 選 main，Folder 選 / (root)，按 Save。
5. 等候 GitHub 部署完成，開啟 Pages 顯示的網站網址。

如果 repository 的 Pages 設定或選項不同，以當前 GitHub 設定畫面為準。

## 檔案

- index.html：藍色入口頁
- login.html：白色登入頁
- menu.html：登入後的藍底功能選單
- record.html：白底藍表格學籍資料頁
- styles.css：四頁的顏色、尺寸、位置與小螢幕適配
- app.js：顯示密碼、模擬登入、未實作按鈕的空操作
- academic.js：按台灣時間計算碩一的入學與學期資料
- assets/：由提供截圖擷取的標題、照片、背景及入口按鈕
- .nojekyll：以靜態檔案部署

## 功能與範圍

- 點擊入口登入按鈕跳至 login.html，返回連結回到 index.html；瀏覽器上一頁也可使用。
- 登入頁的密碼顯示切換可操作。
- 按登入立即清空欄位並跳至 menu.html；任何輸入都可進入，空白也可。不檢查或儲存輸入內容。
- 學籍資料查詢跳至 record.html；回選擇畫面返回 menu.html，登出返回 index.html。
- 未實作的選課、成績、相關系統及忘記密碼按鈕點擊後不執行任何操作或顯示提示。
- 不連線成大認證服務，沒有 OAuth、後端或分析追蹤；學籍頁僅使用本機模擬資料。
- CSP 禁止網路連線與表單提交；輸入欄位沒有 name，不將輸入值放入網址。
- 相關系統及忘記密碼按鈕不跳轉官方服務。
- 已移除四頁左上角的標示，已移除學籍表格右下角註記，登入頁底部保留介面模擬說明。
